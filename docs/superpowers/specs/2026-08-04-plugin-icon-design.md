# Seedance Prompt Generator 图标更新设计

## 目标

为 `seedance-prompt-generator` 增加用户提供的蓝紫色 3D 图标，使插件在 Codex 插件列表、输入区域和详情页中易于识别，并把更新发布到 GitHub。

## 视觉资产

- 原始素材：用户提供的 1024×1024 PNG，包含电影场记板、播放按钮、时间轴和提示词气泡。
- `assets/logo.png`：保留原始 1024×1024 构图，用于插件详情页。
- `assets/icon.png`：从同一素材派生的紧凑方形版本，减少外围留白，用于插件列表和输入区域的小尺寸展示。
- 当前图像的蓝紫配色可同时适配明暗界面，因此本次不增加独立 `logoDark`。

## 插件清单

在 `plugins/seedance-prompt-generator/.codex-plugin/plugin.json` 的 `interface` 中增加：

- `brandColor`：取图标主视觉的蓝紫色。
- `composerIcon`：`./assets/icon.png`。
- `logo`：`./assets/logo.png`。

插件版本从 `1.0.0` 升级到 `1.0.1`。本次不修改技能触发条件、提示词流程或输出契约。

## 文档

在 README 顶部附近加入图标预览，并保留现有安装与使用说明。更新说明应指出 `1.0.1` 新增插件品牌图标。

## 验证

1. 检查两张 PNG 均为正方形、文件可读，且小图标在缩略尺寸下主体清晰。
2. 运行插件结构验证器，确认清单字段和资源路径有效。
3. 运行 Skill 快速验证，确认现有技能内容仍可加载。
4. 重新安装本地插件并确认 CLI 状态为 `installed, enabled`、版本为 `1.0.1`。
5. 提交变更并推送到 GitHub；默认创建草稿 PR，除非仓库权限或工具条件要求改为直接推送。

## 失败处理

- 若紧凑裁切损害图标主体，保留完整主体并只减少外围空白。
- 若清单验证不接受资源字段，按当前 Codex 插件规范修正字段，不回退到未验证的自定义字段。
- 若 GitHub CLI 不可用，先补齐官方 CLI 与登录，再执行发布；不使用未确认的凭据或替代账号。
