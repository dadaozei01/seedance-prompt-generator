# OpenAI 图像表达参考

核验日期：2026-09-19。

## 官方依据

- [OpenAI Image prompting](https://developers.openai.com/api/docs/guides/image-prompting)：描述主体、构图、风格与约束；编辑时明确变化和保留；准确引用图中文字；参考图交代用途。
- [GPT Image 2 型号页](https://developers.openai.com/api/docs/models/gpt-image-2)：核对具体型号与支持入口。提示词指南当前同时包含多个代际，不把新型号的设置套给旧型号，也不替用户升级。

以上是官方表达建议与型号资料，不是固定句数、语言、栏目或参考图分工数量的要求。API 参数与视觉提示词分别处理；ChatGPT UI 不一定暴露相同参数。

## 本插件的适配判断

- 从用户最重视的效果切入，可以先写情绪、材质关系或构图，不必以用途开头。
- 精准编辑：列出本轮全部改动，保留未涉及项。背景改夜景时允许相应反射与照明协调，避免“光线完全不变”与目标冲突。
- 创意重构：明确保留的少数锚点，其余维度按目标重新设计。多图可以一图多用，也可以多图共同定义一个主体。
- 官方的逐项迭代适合定位问题；用户已要求多个变化时不人为拆轮。
- 透明资产按真实入口能力设置与检验；不把透明背景等同于必须去掉一切投影、玻璃或半透明细节。

## 可选内部检查

意图完整、变化与保留无冲突、素材来源清楚、指定文字准确。只有实际生成并查看结果后才能判断画面质量，提示词检查不等于出图成功。
