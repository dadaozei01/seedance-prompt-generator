# ChatGPT Images 2.0 写作指南

## 基本写法

用清晰的自然语言说明最终画面。简单需求用 1–3 句完整句子；商业、图文或多参考任务可分成短段落，但仍以可读性优先。不要默认使用 JSON、权重语法、模型参数或未被用户确认的平台开关。

推荐顺序：用途、主体、动作、环境、构图、风格、光线、约束、画幅比例。只保留会改变结果的描述；若约束相互冲突，以用户最后的明确指令为准。

## 精准编辑

编辑提示词先写改动，再写保留项：

> 只修改 [区域/对象]，把它改为 [目标状态]；其余全部保持不变，包括 [需要锁定的项目]。

“其余不变”应尽可能具体：人物身份和姿势、构图与镜头、背景、光线、材质、已有文字、画幅比例。不要把全图重写成新场景；一次只改一个变量。后续轮次使用“在上一版基础上，仅把……改为……；其他保持不变”。

## 参考图

按上传顺序绑定图像职责，并写排除项。推荐少量、职责不重叠的图片：

- 图 1：锁定主体身份、脸部或商品结构。
- 图 2：仅参考姿势、构图或灯光。
- 图 3：仅参考材质、色彩或版式。

不要默认从任意参考图继承背景、服装、文字或品牌元素。图像职责冲突时，优先主体锁定图，再向用户说明采用的保守假设。

## 图片文字与信息图

把每段要出现的短文字放在引号中，逐字提供，并写清字体气质、大小、颜色和位置。例如：在顶部居中放置 “SUMMER SALE”，现代无衬线粗体，白色，大号；不要出现其他文字、乱码、水印或拼写变体。

信息图按“标题 → 核心数字/结论 → 支撑信息 → 来源或脚注（如用户提供）”安排层级。减少文字密度，保证阅读顺序和留白；不要自行捏造数据、商标或免责声明。

## 一致性与商品工作

人物连续性依靠不变项：保持面部结构、年龄感、自然肤质、自然不对称、发型、服装、姿势和镜头关系。除非用户明确要求，不自动美化、年轻化或重塑面部。商品连续性依靠包装比例、轮廓、标签、Logo 位置、品牌色和材质。若某项必须改变，明确把它从不变项移出。

写正向目标，再添加最少量的负面约束，例如“无多余手指、无变形包装、无随机文字”。负面约束应服务于当前风险，不要用泛滥关键词替代画面描述。
