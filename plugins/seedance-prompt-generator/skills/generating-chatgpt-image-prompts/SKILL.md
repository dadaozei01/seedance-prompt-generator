# ChatGPT / OpenAI 图片提示词

## 定位与自由度

把官方经验作为表达工具，充分发挥创意、联想和专业判断。由用户意图决定内容、结构、语言和详略；模板、句式、描述顺序及检查项都是可选参考。简单任务可以很短，复杂任务充分展开，不设人为字数、镜头数或创意上限，也不为详细而填充。精简指删除无效重复，不是省略有价值的设计。

保留用户明确指定的内容及已核实的平台技术边界；在此范围内可重组构图、融合风格、设计超现实关系与非线性叙事。写实物理和连续性只在题材或用户需要时采用。对用户要求的多项修改一次完整表达；保留项不应包含本轮要求修改的内容。

## 交付与资料使用

先交付可直接使用的成品，把必要的素材关系、文字原文和约束写进成品。栏目、参数说明、备选方案及复用模板按实际需要提供；检查通常在内部完成。用户说“只给提示词”时只给正文。compact / standard / detailed 是用户可选的详略偏好，不是固定长度或必填清单。

只加载与当前任务有关的指南小节；模板仅在有帮助时读取。指南区分官方建议、接口事实和本插件的适配判断，官方建议也可按任务调整。参数与提示词分开：涉及具体版本、入口、支持模式、尺寸或时长上限时核对当前官方资料；普通创意写作不必每次联网。无法确认的设置不编造，也不阻断不依赖该设置的创作。

用户要求实际生成媒体时，本技能辅助可用生成工具完成任务；只有写提示词的请求才止于文本。遵循已有授权，不因本技能额外创建付费任务。多个平台可共享创意与通用技巧，专属参数和素材语法分别适配。

## 平台表达参考

- 从画面目标出发，选择真正影响结果的主体关系、构图、风格和光线；可以使用自然语言、短段落或适合任务的结构。
- 精准编辑说明改动与保留项；创意重构允许重新设计用户放开的维度。单变量迭代是诊断效果的可选办法，不限制本轮修改数量。
- 多参考图说明各图贡献和合成关系，同一张图可以贡献多个维度。复杂文字设计写出确切文案与必要层级，不给无文字画面硬添排版字段。
- 用户指定模型时沿用该模型；ChatGPT 页面与 API 的设置不自动等同。透明背景等能力按具体入口核验。
