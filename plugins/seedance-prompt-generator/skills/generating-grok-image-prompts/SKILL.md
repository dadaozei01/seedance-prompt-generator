# Grok Image 提示词

将用户需求整理成可直接提交给 Grok Image 的自然语言提示词。使用具体名词、材质、光线、镜头和物体关系；不要堆砌孤立标签。

## 先路由任务

- `text-to-image`：无目标图，描述从零生成的主体、场景、构图与画面文字。
- `image-edit`：有目标图，要局部精确修改；先界定唯一改动范围。
- `multi-reference`：两张或以上参考图，需要把每张图绑定到一个明确角色。
- 若用户说“继续编辑/接着改”，按 `continued edit`：以上一次成图为目标图，只增加本轮最小改动。

## 输出方式

默认按以下顺序输出：

1. 【提示词成品】
2. 【负面约束】
3. 【参考图绑定】（无参考图时写“无”）
4. 【参数建议】
5. 【风格锚点】
6. 【一致性检查】

仅当用户明确说“保存成模板”“给我复用短句”“以后继续用这个风格”“做成可复用版本”或“下次沿用这套结构”时，才追加【下次可复用短句】；普通任务不输出。若用户说“只给提示词”，只输出【提示词成品】，仍在该段内保留必要的约束与参考图绑定。

## 写作规则

1. 先选密度：`compact`（一段核心画面）、`standard`（默认，完整可用）、`detailed`（复杂关系、文字或多图时）。用户未指定时用 standard。
2. 把本轮用户明确提出的尺寸、比例、平台限制、禁用元素、品牌、时间或文字要求视为动态当前任务约束；它们优先于通用模板。
3. 明确关系：例如“红伞遮在女孩头顶，伞沿挡住后方霓虹”，不要只列“女孩、红伞、霓虹”。
4. 画内文字必须逐字加引号，例如：`招牌准确显示“夜航书店”`；禁止以近似拼写代替。
5. 多参考图中，每张图只能承担一个角色：人物身份、服装、产品外形、环境、构图或色彩之一；同时说明该图不应迁移什么。

## 编辑协议

编辑提示词必须包含以下英文原句：`Only modify`、`Keep everything else unchanged`、`Do not change`。描述单一、可验证的最小差异，锁定人物、姿势、构图、光线、镜头、背景和文字等未变部分；不要借编辑请求重写整张图。

## 交付前 lint

检查：任务路由正确；主体和关系明确；画内文字逐字带引号；编辑包含三句锁定语；每张参考图有唯一角色及排除项；没有与用户当前约束冲突；不含标签堆砌。只在需求有歧义、或用户要求可复用模式时加载 examples。
