# Grok Image 表达参考

核验日期：2026-09-19。

## 官方依据

- [xAI Image Generation](https://docs.x.ai/developers/model-capabilities/images/generation)：用自然语言提供画面描述，接口设置单独传递。
- [xAI Image Editing](https://docs.x.ai/developers/model-capabilities/images/editing)：提供目标图片与编辑说明，多轮编辑可把上一轮输出作为新输入。

已核验页面没有要求每次编辑都包含三段固定英文，也没有把参考图限制为每图只能贡献一个维度。不要将本插件习惯标成官方规则。

## 本插件的适配判断

- 从零创作可自由设计主题、情绪、空间、材质和风格；需要控制相互遮挡或布局时，具体说明对象关系。
- 精准编辑写清全部修改项及不变项；创意重构保留用户指定锚点，其余按目标设计。
- 一图可以参考颜色与材质，多图也可共同建立身份。只在参考冲突影响结果时明确优先级或请求必要澄清。
- 用户指定画中文字时保留原文；确切排版细节按设计需要给出。
- 多图数量、输出设置和模型名称按当前入口核验，不假设 App 与 API 完全一致。

## 可选检查

成品是否可独立使用、所指目标图是否准确、变化与保留是否矛盾、参数是否有依据。具体语言与篇幅由用户和任务决定。
