# Grok Image 工作指南

## 从零生成

用自然语言按“主体 → 可见特征 → 动作 → 环境 → 物体关系 → 光线/镜头 → 文字 → 约束”组织。选择 compact、standard 或 detailed 密度；默认 standard。把用户本轮提出的比例、尺寸、品牌、禁区和时效要求作为最高优先级的动态约束。

## 精确编辑

先说清目标图与唯一变化，再写 `Only modify ...`。用 `Do not change ...` 列出必须锁定的身份、姿势、构图、背景、镜头、光线、文字与其余道具；以 `Keep everything else unchanged.` 收束。只改最小范围，不扩写成重生成。

## 继续编辑

把上一轮输出图视为唯一目标图，继承已锁定内容，只描述新增的一处变化。若用户的新增要求与先前锁定项冲突，指出冲突并要求选择；不要擅自覆盖。

## 多参考图

逐张编号并绑定一个角色，例如“参考图 1：人物身份与脸部特征；不要迁移服装、姿势或背景”。每张图的职责不可重叠，最后写出合成关系与优先级。

## 画内文字

把所有应出现的文字逐字放入中文引号或英文引号，例如“SPRING MARKET”。注明位置、字体气质和可读性；不得把文字改写为近似字词。

## 动态约束

用户明确指定的画幅、内容限制、产品事实、品牌规则、日期/季节、已有角色和审核要求优先。没有给定时，不虚构品牌或不可见细节。

## Prompt lint

- 任务是否选对：从零、编辑、继续编辑或多参考？
- 是否写出了看得见的对象关系，而非标签列表？
- 编辑是否同时含 `Only modify`、`Keep everything else unchanged`、`Do not change`？
- 多图是否一图一角色并写明排除项？
- 文字是否逐字引用，且当前任务约束无冲突？
