# Nano Banana / Gemini 表达参考

核验日期：2026-09-19。

## 官方依据

- [Google Nano Banana image generation](https://ai.google.dev/gemini-api/docs/image-generation)：参考其中图像编辑、多图合成与 Best practices。官方建议提供具体细节和意图，复杂场景可以分层表达，用构图语言控制视角，并通过对话迭代。可以正面描述期望场景来减少负面词堆积。
- [Google Prompt design strategies](https://ai.google.dev/gemini-api/docs/prompting-strategies)：指南和模板是实验与改进的起点。

这些是建议，不是固定句式或必须填写的槽位。不同 Gemini 图像型号的素材能力与设置存在差异，以任务实际型号和入口为准。

## 本插件的适配判断

- 具体描述用于提高控制力；抽象、极简、留白需求也可以用简洁语言成立，不自动添加装饰或写实细节。
- 多图明确贡献与最终关系：例如图1提供配色和陶瓷釉面，图2提供构图；同一图可贡献多项。
- 编辑一次完成用户本轮要求的变化，保留指定身份或品牌细节；重构任务可以开放场景、光线和风格。
- 用途有助于设计时说明用途，无需每条都以“用途：”开头。准确文字及层级只用于有文字的任务。
- 迭代以用户选定结果为起点；只有为了诊断变化来源时才建议逐项试验。

检查放在内部：参考关系、用户文字、修改范围与构图是否一致。不要把“生成提示词”宣称为“已经验证成图”。
