# 生成 Nano Banana 提示词

将明确面向 Nano Banana 或 Gemini 生图的需求写成自然、可执行的图像指令。先说明图片用途，再锁定不变主体并描述本次画面变化；让每张参考图各司其职。

## 工作流

1. 判断用途与任务：广告、电商、社交媒体、海报等用途；文生图、局部编辑、多参考图、人物一致性、商品与品牌一致性、图片文字或模板。
2. 阅读 [Nano Banana 指南](references/nano-banana-guide.md)；再只阅读 [对应模板](references/templates.md) 的一个相关章节。
3. 用叙事句按“用途 → 主体 → 动作 → 场景 → 构图 → 镜头 → 光线 → 风格/材质 → 文字 → 输出”组织，不堆砌关键词。
4. 有参考图时逐图指定职责和排除项；编辑时写清“改哪里、改成什么、其余保持什么”。
5. 用户同时要求多个平台时，分别输出并明确标注“【Nano Banana 版】”；不得混入其他平台的专属规则、参数或提示结构。
6. 用户说“只给提示词”时，仅输出【提示词成品】；否则使用下列完整交付结构。
7. 使用 `compact`、`standard`、`detailed` 控制复杂度；按用户要求真实删除重复内容。负面约束只为当前任务动态生成。

## 输出结构

依次输出：

1. 【提示词成品】：可直接复制到 Nano Banana/Gemini 的完整提示词，以用途开头。
2. 【负面约束】：只列当前画面最可能出现的跑偏问题。
3. 【参考图绑定】：逐图写明参考职责与排除项；没有参考图时写“无”。
4. 【参数建议】：只写用户已提供或官方已确认的平台设置；没有可靠设置时写“按平台默认设置”。
5. 【风格锚点】：提炼可重复使用的审美、光线、色彩和材质规则。
6. 【一致性检查】：明确检查用途、主体身份、参考图职责、构图、文字、光影、人体或商品结构是否一致。

只有用户明确说“保存成模板”“给我复用短句”“以后继续用这个风格”“做成可复用版本”或“下次沿用这套结构”时，才追加【下次可复用短句】；普通任务不输出。

平台不明确时不要调用本 Skill；按通用图像需求处理并简短确认目标平台。一次迭代只改变一个可观察变量。
