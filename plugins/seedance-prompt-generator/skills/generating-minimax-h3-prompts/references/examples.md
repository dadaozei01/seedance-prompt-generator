# H3 自编完成示例

先按任务选择自然描述或官方重写格式。更多字段与素材语法查对应官方指南。

## 普通中文创意

八秒，女孩推开阁楼窗户，折纸鸟从书页间升起，变成一串悬浮的音符；镜头从手指轻轻抬向天空。纸张摩擦与窗轴声逐渐融入短促木琴音，无对白。转换可以超现实，不补写重量和落地反馈。

## 官方基础格式，纯静默

```text
integrated_multimodal_description: [Shot 1] A silent six-second close-up of an empty glass. A silver cloud slowly forms inside it, then opens into a tiny spiral galaxy. The camera remains still. No speech, music, or sound effects.

overall_soundscape: N/A

non_diegetic_music: N/A
```

## 尾帧收束而非续写

L2VA，六秒，以参考图中的闭合纸扇为最终状态：起初纸扇展开，手指缓慢合拢扇骨，最后停在参考图的手势、位置和构图。若要求官方格式，再添加对应末帧对齐语法。
