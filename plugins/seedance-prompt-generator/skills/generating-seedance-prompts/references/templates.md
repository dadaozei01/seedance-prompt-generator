# Seedance 任务模板

只读取并套用与当前任务对应的模板。占位符必须替换成用户内容或合理补全结果。

## 1. 文生视频

```text
生成一条[时长]秒的[题材]视频。[主体]在[地点]完成[核心事件]，整体为[风格]，采用[核心镜头语言]。

主体与场景：[主体外形、服装、气质]；[时间、天气、环境、光影]。

0–[时间]秒：[景别/视角]，[画面与动作]，[情绪]。镜头[运动]。[台词/音效]。
[时间]–[结束]秒：[画面、动作结果、镜头和声音]。

全局：[色调、节奏、质感、声音、物理真实性、一致性与结尾落点]。
```

## 2. 图生视频或首尾帧

```text
@图片1作为首帧，并作为[主体/场景]参考；@图片2作为尾帧，只参考[结果画面]。保持主体外形、服装、道具和场景结构一致。

[一句话概述]
0–[时间]秒：[从首帧自然启动的动作与运镜]。
[时间]–[结束]秒：[动作过渡与尾帧收束方式]。
全程避免突然变形、跳帧或无因切镜。
```

## 3. 多模态综合参考

```text
【素材分工】
@图片1作为主体1的[外形/服装]参考。
@图片2只参考[场景/产品/道具]。
@视频1参考[动作/运镜/节奏/创意]，不参考[人物/场景]。
@音频1参考[音色/BGM/节奏]。

【故事与时间轴】
[一句话概述]
0–[时间]秒：[节点1]。
[时间]–[时间]秒：[节点2]。
[时间]–[结束]秒：[节点3和结尾]。

【全局】[风格、光影、声音、主体与素材一致性]。
```

## 4. 视频编辑

```text
编辑@视频1。只将[目标对象]在[时间范围/全片]修改为[目标效果]。

保持原视频的[人物长相、服装其他部分、动作、构图、机位、背景、光影、节奏、人声、字幕等指定项目]不变。修改后的[目标对象]在全片颜色、形状、材质、遮挡和运动中保持一致，并符合原场景光照与物理关系。
```

## 5. 视频延长

```text
将@视频1延长[新增时长]秒。以下提示仅描述新增部分：

[原片结束时间]–[时间]秒：[紧接原片的动作、方向、速度和情绪]。
[时间]–[新结束时间]秒：[后续事件与结尾落点]。

保持主体外形、服装、道具、运动惯性、空间结构、机位、光影、色调、环境音和音乐节奏与原片无缝连续，不重复原片已有剧情。
```

## 6. 30–180 秒超长视频

```text
生成一条[总时长]秒的[类型]长视频。

【总故事】[主角、目标、冲突、转折、结局、风格和受众感受]。

0–[时间]秒｜[章节名]：[场景目标、核心动作、关键镜头、声音]。
[时间]–[时间]秒｜[章节名]：[发展与转折、关键镜头、声音]。
[时间]–[结束]秒｜[章节名]：[高潮、结果、收束镜头、声音]。

全片重复使用以下锚点：[角色外形、服装、产品、场景色彩、镜头风格]。章节转场使用[方式]，保证时间、空间、人物关系和声音连续。
```

```text
[对应模板生成的完整提示词]

[只列与当前任务相关的防跑偏项]

【素材绑定】
[逐项用途；无素材则写“无”]

【参数建议】
模型：Seedance [版本]

时长：[秒]
画幅：[比例]
分辨率：[建议]

【一致性检查】
- 时间轴：[通过/需确认]
- 主体与道具：[通过/需确认]
- 素材用途：[通过/无素材]
- 镜头与声音：[通过/需确认]
- 正负约束：[通过/需确认]

【下次可复用短句】
按这次的[风格锚点]，为我生成一条[主题]的 Seedance 视频提示词。
```
