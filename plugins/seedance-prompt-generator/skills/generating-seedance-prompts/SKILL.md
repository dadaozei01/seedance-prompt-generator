# 生成 Seedance 视频提示词

## 核心原则

把用户的创意改写成可直接复制进 Seedance 的导演执行稿。默认使用 Seedance 2.5；除非关键素材缺失且无法推断，否则直接合理补全，不用问题打断用户。

## 工作流程

1. 判断任务：文生视频、图生视频/首尾帧、多模态参考、视频编辑、视频延长或超长视频。
2. 读取 [references/seedance-guide.md](references/seedance-guide.md)。需要输出具体结构时再读取 [references/templates.md](references/templates.md)，只使用对应模板。
3. 提取用户已给出的主体、场景、事件、风格、素材、时长、画幅、镜头、声音和约束；缺项按内容合理补全。
4. 给多角色编号为“主体1、主体2”；给每项素材写明参考维度与排除维度，例如“@视频1只参考动作和运镜，不参考人物与场景”。
5. 短视频用连续且不重叠的时间段。每段只放一个核心剧情节点，并写清画面、动作、情绪、景别/视角、运镜、台词和音效。
6. 把运镜绑定到动作，不堆砌互相冲突的镜头词。让台词长度符合时间段。
7. 在结尾补全全局风格、节奏、光影、声音、物理真实性和主体一致性。
8. 生成负面约束并完成一致性检查。

## 条件规则

- 用户只给一句需求：补全时长、场景、动作节奏、运镜、光影、声音和负面约束，保持核心创意不变。
- 用户提供素材：必须使用 `@图片1`、`@视频1`、`@音频1` 等名称，并逐项限定用途。
- 多角色或多产品：编号并固定外形、服装、道具、站位与关系，防止串脸和错位。
- 视频编辑：明确修改对象、作用时间、保持不变项与全片一致性。
- 视频延长：提示词只描述新增片段，同时要求动作、光影、空间和声音与原片连续。
- 30–180 秒超长视频：使用章节时间段、场景目标和关键镜头节点，不逐秒堆砌。
- 用户说“做成模板”：使用 `[角色身份]`、`[场景]`、`[动作]`、`[镜头景别]` 等占位符。
- 未要求字幕：不主动添加字幕；负面约束写明不要随机字幕、水印和无关文字。

## 输出契约

按以下顺序交付，优先给完整成品，少讲概念：

1. `【提示词成品】`：完整可复制提示词。
2. `【负面约束】`：单独列出防跑偏要求。
3. `【素材绑定】`：逐项说明素材用途；无素材时写“无”。
4. `【参数建议】`：版本、模式、时长、画幅、分辨率及必要设置。
5. `【一致性检查】`：用简短清单确认时间、主体、素材、镜头、声音和约束。
6. `【下次可复用短句】`：给一条以后可直接调用本风格的短句。

## 交付前检查

- 时间段连续，总时长匹配，无重叠或空档。
- 主体、素材、服装、道具编号没有混用。
- 每个核心动作有合适镜头，复杂度符合时长。
- 台词、音效和音乐出现时机明确。
- 正向描述、保持不变项与负面约束不冲突。
- 成品可以直接使用，不只是一句短提示词或写作建议。

## 常见错误

|错误|修正|
|---|---|
|只写“参考视频”|明确参考动作、镜头、节奏、声音或创意中的哪一项|
|多个角色不编号|使用主体1、主体2，并固定各自外观与道具|
|同时堆很多动作和运镜|按时间段拆分，一个节点一个核心动作|
|编辑要求只有“改成……”|补充修改范围、保持不变项和全片一致性|
|负面词泛滥|只约束最可能发生且影响成片的问题|
