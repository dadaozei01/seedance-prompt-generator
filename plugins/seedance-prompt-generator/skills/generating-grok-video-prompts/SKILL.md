# Grok Video 提示词

将创意写成连续、可执行的 Grok 视频提示词：动作因果清晰，镜头服务动作，素材身份不串位。

## 工作流程

1. 精确路由：无首帧/参考素材为 `text-to-video`；给定首帧并要求延续为 `image-to-video`；给定参考视频以借动作、运镜或节奏为 `reference-to-video`。不要混用模式名。
2. 读取 [Grok Video 指南](references/grok-video-guide.md)。需要结构时读取 [模板](references/templates.md)；歧义、物理动作或复用样式时读取 [示例](references/examples.md)。
3. 绑定四类角色：角色/主体负责身份与动作，对象负责可交互物，环境负责空间与可见反应，`Camera` 只描述与该动作同步的镜头。
4. 将动作写为连续链：预备（anticipation）→执行→中间状态→收势（follow-through），明确 `weight`、`inertia` 与 environmental response。按时长缩放动作数，不用密集的 Seedance 时间戳块。
5. 对 I2V 不复述已提供首帧的外观、构图或静态场景，只写从首帧开始的变化。参考视频不是首帧（不是第一帧）；它只贡献被请求的动作/镜头/时序，不继承人物、物体、场景或画风。
6. 写动态的当前任务约束（用户指定的人物、首帧、时长、画幅、固定镜头、禁改项优先）；再做提示词 lint。

## 输出契约

- 默认依次输出：`【提示词成品】`、`【负面约束】`、`【素材绑定】`、`【参数建议】`、`【一致性检查】`。
- 用户说“只给提示词”时，仅输出 `【提示词成品】`及可直接复制的正文。
- 支持 compact（核心动作+镜头+约束）、standard（默认）、detailed（补足物理、光线与环境反应）。
- 仅当用户明确说“保存成模板”“给我复用短句”“以后继续用这个风格”“做成可复用版本”或“下次沿用这套结构”时，附 `【下次可复用短句】`。

## 提示词 lint

- 模式与素材一致；每个角色、对象、环境、`Camera` 职责清楚且无冲突。
- 每个主要动作都有预备、接触/中间状态、收势及相应重量、惯性、环境反馈。
- 固定镜头时不出现推拉、摇移、跟拍或切镜；镜头与动作无互相矛盾的指令。
- I2V 不重述首帧；参考视频不被写成首帧或身份/场景来源；多参考冲突时按用户优先级或要求澄清。
- 动作数量、镜头变化和信息密度与时长匹配；负面约束只覆盖本任务高风险偏移。

## 常见错误

| 错误 | 改法 |
|---|---|
| 跳跃像瞬移 | 写下压蓄力、离地、空中姿态、落地压缩与尘土/地面反应 |
| 镜头词堆叠 | 每个动作节点绑定一个明确 `Camera` 行为 |
| 参考视频变成首帧 | 写明“仅参考[动作/镜头/时序]，不继承其余维度” |
